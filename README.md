# ⚽ 7M 축구 최종배당 수집기

Streamlit 기반 7M 축구 배당 데이터 수집/분석 프로그램.

## 기능

- 날짜 범위 수집
- 업체/CID 선택
- 최종배당 저장
- 동일배당 분석
- 승/무/패 건수
- 승/무/패 비율
- 배당 암시확률
- 실제 결과확률과 비교
- 부족/초과 확률 표시
- 업체별 저장 건수
- 실패 날짜 표시
- 자동 재시도
- 재시도 실패 날짜 건너뛰기
- 수집 중단
- 마지막 정상 데이터 날짜 표시
- SQLite DB 저장
- 수동 최종배당 입력
- CSV 다운로드
- 페이지 연결 진단
- 로그 숨김
- 브라우저 결과 음성 안내
