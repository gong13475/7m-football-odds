# ⚽ 7M 축구 최종배당 수집 · 분석기

7M의 1X2 축구 최종배당 데이터를 수집하고
동일배당 과거 경기의 실제 결과를 분석하는 Streamlit 프로그램입니다.

## 주요 기능

- 7M 데이터 전용
- 지정 날짜 수집
- 날짜 범위 수집
- CID 선택
- 최종배당 저장
- SQLite DB
- 중복 경기 방지
- 실패 자동 재시도
- 재시도 실패 날짜 건너뛰기
- 수집 중지
- 마지막 완료 날짜 표시
- 발견 건수
- 신규 저장 건수
- 실패 날짜
- DB 전체 건수
- 업체별 저장 건수
- 동일 최종배당 검색
- 승/무/패 전체 건수
- 배당상 확률
- 실제 발생률
- 부족확률
- 음성 입력 결과 처리
- 분석 결과 음성 기능 확장 가능
- 7M 연결 진단
- 서버 응답 및 History JS 확인
