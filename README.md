# ⚽ 7M 축구 최종배당 수집 · 분석기

7M의 1X2 축구 최종배당 데이터를 수집하고

동일 최종배당이 과거에 실제로 어떤 결과를 만들었는지
SQLite 데이터베이스를 이용하여 분석하는 Streamlit 프로그램입니다.

---

# 주요 기능

## 데이터 수집

- 7M 전용
- 지정 날짜 수집
- 날짜 범위 수집
- CID 선택
- 1X2 최종배당 수집
- 경기 결과 수집
- SQLite 저장
- 중복 경기 방지
- 실패 자동 재시도
- 재시도 실패 날짜 건너뛰기
- 백그라운드 수집
- 수집 중지
- 마지막 완료 날짜 표시

## 수집 현황

- 진행 날짜
- 전체 날짜
- 발견 경기 수
- 신규 저장 경기 수
- 실패 날짜 수
- 성공 날짜 수
- 마지막 완료 날짜
- 수집 로그

## 분석

동일한 1X2 최종배당을 DB에서 검색합니다.

예:

승 1.50
무 3.50
패 5.00

검색 결과를 기준으로:

- 전체 경기
- 승 횟수
- 무 횟수
- 패 횟수
- 실제 승률
- 실제 무승부율
- 실제 패율
- 배당상 확률
- 실제 발생률
- 부족확률

을 계산합니다.
